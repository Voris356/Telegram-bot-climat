# Telegram-бот для услуг по кондиционерам

Русскоязычный бот с меню услуг, краткими ответами на частые вопросы и формой
заявки. Бот не придумывает цены и условия выезда: их можно добавить в
настройки после подтверждения владельцем бизнеса.

## Что умеет бот

- рассказывает об установке, ремонте, проверке/заправке хладагентом и профилактике;
- отвечает на вопросы о выборе кондиционера, слабом охлаждении, обслуживании и цене;
- собирает имя, телефон, район/адрес и описание задачи после согласия клиента;
- отправляет заявку в личный Telegram владельца;
- не сохраняет заявки в собственной базе данных.

Ответы в первой версии подготовлены заранее, без генеративного ИИ. Это помогает
не обещать неподтверждённую цену, срок выезда или технический результат.

## Запуск

Нужен Python 3.10 или новее.

1. Создайте бота через `@BotFather` в Telegram.
2. Скопируйте `.env.example` в `.env` для локального запуска и заполните настройки.
   Не добавляйте `.env` или токен в GitHub.
3. Установите зависимости и запустите:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python bot.py
   ```

   В Windows активируйте окружение командой `.venv\\Scripts\\activate`.

Для размещения на Replit или другом хостинге задайте переменные в Secrets /
Environment Variables, а не в исходном коде:

- `TELEGRAM_BOT_TOKEN` — токен из `@BotFather`;
- `ADMIN_CHAT_ID` — ID личного чата владельца;
- по желанию `BUSINESS_NAME`, `SERVICE_CITY`, `SERVICE_PHONE`.

Чтобы узнать `ADMIN_CHAT_ID`, запустите бота, откройте его от имени владельца и
отправьте `/start`, затем `/id`. Бот должен быть постоянно запущен на хостинге,
который поддерживает работающий Python-процесс. Пока `ADMIN_CHAT_ID` не настроен,
бот отвечает на вопросы, но не принимает заявки.

## Перед запуском для клиентов

- Укажите реальные название, город обслуживания и телефон в переменных окружения.
- Проверьте тексты услуг, фактическую зону выезда и порядок обработки заявок.
- Добавьте актуальный прайс только после его подтверждения.
- Не просите клиентов отправлять паспортные, банковские или иные лишние данные.
- Храните токен только в секретах хостинга; при случайной публикации перевыпустите
  его через `@BotFather`.

Для проверки текстов выполните:

```bash
python -m unittest discover -s tests
```
